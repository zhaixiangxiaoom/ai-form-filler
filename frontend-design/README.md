# Frontend Design

A Qoder plugin wrapping the [Anthropics frontend-design skill](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md).

## What it does

Provides guidance for distinctive, intentional visual design when building new UI or reshaping an existing one. It helps with aesthetic direction, typography, and making choices that don't read as templated defaults.
